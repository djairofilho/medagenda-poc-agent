# MedAgenda 3.0 — POC de arquitetura de agentes e API

Esta versão demonstra uma arquitetura organizada por domínio para um agente de agendamento médico e sua API. Os dados usados na demonstração são fictícios.

## Destaques

- Módulos de conversas, consultas, horários, pacientes e clínica, com routers e serviços próprios.
- Conversas em LangGraph com checkpoints persistentes e reset de sessão.
- Adaptadores SQLAlchemy, Alembic e LangGraph para PostgreSQL ou SQLite, escolhidos por configuração.
- Reserva transacional de horários, confirmação explícita e resposta idempotente para confirmação repetida.
- Traces opcionais no Langfuse com mascaramento de dados pessoais e conteúdo clínico.
- Evals reproduzíveis com conversas sintéticas, regras objetivas e juiz LLM opcional apenas para experimentos.
- Dependências gerenciadas com `uv` e validadas automaticamente em CI.

## Executar

Siga o [README](https://github.com/djairofilho/medagenda-poc-agent/blob/3.0/README.md) para iniciar com PostgreSQL ou SQLite. A configuração de um provedor de modelo é necessária para usar `/chat` fora dos testes e evals simulados.

## Escopo da POC

Esta release não inclui autenticação nem OAuth. Use somente dados fictícios; os endpoints administrativos e o fluxo de pacientes não estão prontos para uso com pacientes reais. A estrutura de persistência da POC anterior não é migrada automaticamente.
